# 🌐 AI Studio Pro — Official Website

This repository contains the source code for the official landing page of **AI Studio Pro**, hosted via GitHub Pages.

## 🔗 Live Site
[Visit the AI Studio Pro Website](https://www.justgohome.net)

## 💻 About the App
AI Studio Pro is a high-performance, privacy-first desktop workspace that equips developers and creators with local document RAG search, live web browsing, sandboxed Python script execution, and multi-model completions.

## 🛠️ Website Stack
* Single-page HTML5 architecture
* Tailwind CSS via CDN for rapid styling and native dark mode
* Fully responsive layout with dedicated advertisement slots
